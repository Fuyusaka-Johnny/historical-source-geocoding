# 项目目标与研究复盘

## 项目目标与工作流设计

本项目源于作者@Fuyusaka-Johnny在日本动物史研究过程中的空间分析需求。先行研究关注城市空间中的人与动物关系，并尝试将动物作为具有历史能动性的研究对象。基于这一研究取向，希望从日本历史史料中整理犬类活动的地点与事件信息，探索其空间分布及与城市生活的关系。

初期计划选取两部史料，利用日本国立国会图书馆已有的 OCR 成果获取文本，通过大语言模型批量抽取地名、事件内容及时间信息，再关联地名数据库中的经纬度，生成结构化记录，最终接入 ArcGIS Pro 进行地图标注与空间分析。

史料文本与地名坐标采用不同的数据来源：日本国立国会图书馆的 OCR 成果用于获取史料文本；[人间文化研究机构（NIHU）与 H-GIS 研究会的历史地名数据](https://www.nihu.jp/ja/database/source_map.html)用于提供地名及坐标候选。

**研究工作流设计如下，其中 Excel 表格整理属于研究端的人工整理环节，GIS 导入与空间分析尚未接入程序：**

1. 文本获取与预处理：从日本国立国会图书馆获取经由国立国会图书馆所开发 OCR 工具所提取文本（本工程不包含 OCR 识别、提取文本功能）。
2. 文本分块与信息抽取：将文本分块输入模型，依据提示词抽取日期、人物、地点与事件，输出 JSON 格式的记录。犬类相关事例是研究筛选目标；当前提示词提取一般史料信息，相关性仍需人工筛选。
3. 结构校验与原文核对：检查字段结构与数据类型，并回查原文，确认抽取内容是否有文本依据。程序可检查引文是否出现在输入文本中，具体解读仍需人工核验。
4. 地名匹配与候选核验：使用抽取出的地点表达查询地名数据库；对于同名候选、空间指代及无法匹配的记录，结合上下文与研究资料进行人工核验。程序保留候选与出处，不自动判定历史地点。
5. 结构化记录整理：研究资料主要使用 Excel 整理，字段设计包括 ID、Name、Longitude、Latitude、Period、Category，并补充事件概要、史料出处、原文片段和定位状态，以保留核验依据。当前程序导出 JSON，整理成研究用表格需要人工处理或另行转换，尚未提供 Excel 自动导出。
6. GIS 导入与可视化：计划将具有可靠坐标的研究记录转换为点要素，导入 ArcGIS Pro；无法确定坐标的记录保留为空，不强行定位。
7. 空间分析与研究解释：在样本规模和定位质量允许的情况下，进一步观察事件的空间分布，并结合史料语境解释其研究意义。

原型阶段主要探索了信息抽取与地名匹配环节，尚未形成从史料输入到 GIS 可视化的完整自动化流程。当前程序的接口、字段与输出格式见[技术流程与实现说明](technical.md)。

## 问题一：空间指代缺少明确的地理参照

史料中出现“御所”“宅内”“家内”等表达。这类表达的定位依赖叙述者身份、事件时间和上下文，不能仅凭名称直接对应数据库中的某个坐标。例如，“宅内”需要先确定所指住宅，“御所”也需要结合历史时期和具体语境判断。

这一问题涉及空间指代消解与历史地名实体链接：不仅要识别地点表达，还要判断它指向哪个历史地点。

我尝试结合 AI API 与联网检索辅助判读，但在少量案例验证中，公开可检索的研究资料不足以支持可靠定位，所得结果仍需要人工核验。限制主要在于相关证据难以检索或直接获取，不能据此推断所有相关研究资料均存在统一的公开权限限制。

进一步解决这一问题，需要建立面向特定史料的历史地点参考资料库，整理人物与住所的关系、地点异名、适用年代及研究文献依据。其主要成本在于证据搜集、资料整理和地点核验，而非数据库软件本身的搭建。考虑到这一工作与论文核心问题的关联程度，我未继续扩大该部分建设。

## 问题二：同名地名存在多个候选地点

虽然研究范围主要设定为京都，但地名数据集中存在同一名称对应多个地点记录的情况。仅按名称匹配，无法判断哪个候选地点对应史料中的实际地点。

这一问题属于同名地名消歧。同名记录可能指向不同地点，不能直接视为重复数据删除，需要进一步结合行政层级、历史时期、相邻地点及文本语境筛选候选。

我尝试通过经纬度范围缩小候选集合。但现代地图上的京都范围不能直接替代研究时段中的城市空间范围；以现代范围筛选，也可能误排除史料中涉及的城外地点。因此，经纬度范围只能作为初步筛选条件，不能单独作为历史地点判定依据。若要建立可靠的历史空间范围，还需要结合历史地图与相关研究另行论证。由于这会引入较多独立于论文核心问题的工作，我停止了进一步推进该方案。

当前程序保留同名候选，便于人工对照；上述联网检索、地理范围筛选及历史语境判断，属于研究中的探索与核验方法，尚未集成为自动处理功能。

## 为什么没有继续接入 ArcGIS

项目初期希望尽可能全面地抽取史料中的犬类相关记录，再通过地理分布探索潜在的研究问题。但在原型验证中，发现全面抽取不仅涉及模型输出，还依赖大量历史语境解释与地点核验，难以直接实现自动化处理。

接受导师建议后，我将研究范围收缩为与论文问题意识直接相关的宠物犬等事例。筛选后，相关样本仅有约 10 条。对于这一规模，逐条查证和人工标注已能满足当前研究需求，继续开发批量定位与 GIS 导入流程的收益有限。

因此，研究中的批量处理流程在原型验证阶段停止扩展，后续研究转向人工核验。未继续接入 ArcGIS，是根据研究范围、样本数量及核验成本作出的范围调整；ArcGIS 地图标注与空间分析保留为后续扩展方向。
